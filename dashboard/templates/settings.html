Settings

Synology NAS connection

Used to configure every server you link. No NAS password is stored — it's asked for once when linking a server, only to authorize that server's key.

Tailscale auto-setup (optional but recommended)

Paste a Tailscale auth key here and the enroll command will install + connect Tailscale on every new server automatically — true one-command setup. Create it at login.tailscale.com → Settings → Keys → Generate auth key: enable Reusable, set the longest expiry (the key's expiry only limits how long you can enroll new servers with it, not the servers themselves — but still disable key expiry per machine afterwards).

Defaults for newly linked servers

Install an update

Upload a new LinuxWebsitesBackup.tar.gz bundle and the panel updates itself — no SSH needed. Your settings, servers, login and keys are kept. The panel restarts automatically (a few seconds of downtime).
