How to create an auth key

In the Tailscale admin console, go to Settings → Keys → Generate auth key. Enable Reusable, choose an expiry, and paste the tskey-auth-… key here. Key expiry affects new enrollments. Manage each machine's key expiry in Tailscale separately. Type clear to remove a saved key.
