Option A — run one command on the server (recommended)

SSH into the web server and paste this as root. It downloads the backup agent from this panel, installs it, connects the server to the panel, and it appears on the Servers page automatically:

curl -fsSL {{ panel_url }}/enroll.sh | sudo bash -s -- {{ panel_url }} {{ token }}

If a Tailscale auth key is saved in Settings, this command also installs and connects Tailscale on the server automatically (needed to reach the NAS) — nothing else to do on the server.
If the server's SSH runs on a non-standard port, append the IP and port: … {{ token }} <server-ip> <ssh-port>
When it finishes, come back here, open the server and click Complete setup (you'll enter the NAS password once).

Option B — link with a root password

The panel connects to the server with a password once (never stored) and does everything itself, including the agent install.
